# QRead — Online Qur’an Reading Platform

**QRead** adalah website modern untuk membaca Al-Qur’an secara online dengan tampilan yang bersih, sederhana, dan nyaman digunakan di berbagai perangkat. Website ini dirancang untuk memberikan pengalaman membaca yang fokus, cepat, dan mudah diakses kapan saja.

Proyek ini dibangun menggunakan **Next.js (App Router)** dan di-deploy menggunakan **Vercel**, sehingga memiliki performa yang optimal serta waktu loading yang cepat.

## ✨ Fitur Utama
- Tampilan antarmuka sederhana dan nyaman dibaca
- Responsif untuk desktop dan mobile
- Performa cepat berkat Next.js & Vercel
- Struktur modern dengan App Router
